# 응애톡 검증 기록 — 2026-10-01

## 실행 결과

`npm ci`, `npm run build`, `npm run check`, `npm test` 통과.
실제 배포용 Worker와 MediaPipe WASM, 두 모델의 가중치를 사용했다.
라이프사이클 테스트에서는 무음·잡음·불확실·오류·분석 끄기·종료 후에도
마지막 후보와 원래 시각을 유지하고, 카메라 전환 시에도 보존되는 것을 확인했다.
새 듣기 시작은 결과를 초기화한다. 중복 응답은 합의 횟수로 세지 않는다.

## 실제 녹음 샘플

출처: [ESC-50](https://github.com/karolpiczak/ESC-50), 원본 분류와 파일 목록은
[metadata](https://github.com/karolpiczak/ESC-50/blob/master/meta/esc50.csv).
아기 울음 2개, 개 짖음·알람·청소기 각 1개의 기존 녹음을 사용했다.
각 파일의 0초 및 1.5초부터 3.072초 구간을 16kHz mono Float32로 입력했다.
원본/입력 해시는 `fixture-sources.json`, `validation-2026-10-01.json`에 기록했다.
음원은 저장소나 서비스에 재배포하지 않는다. 사용 시 원본 데이터셋 라이선스를 확인한다.

| 실제 분류 / 파일 | 0초 구간 | 1.5초 구간 |
| --- | --- | --- |
| 아기 울음 1-187207-A-20 | 다른 소리로 감지 | 울음 불확실 |
| 아기 울음 1-211527-A-20 | 다른 소리로 감지 | 원인 모델 진입: belly_pain |
| 개 1-100032-A-0 | 다른 소리로 감지 | 다른 소리로 감지 |
| 알람 1-13613-A-37 | 잡음으로 보류 | 잡음으로 보류 |
| 청소기 1-100210-A-36 | 잡음으로 보류 | 잡음으로 보류 |

울음 4개 구간 중 3개가 원인 모델에 도달하지 못했다. 입력이 실제 울음이어도
결과가 안 나오는 사례가 확인됐다. 비울음 6개 구간은 원인 모델에 진입하지 않았다.
마지막 울음 구간의 belly_pain은 **모델 출력일 뿐**, 데이터셋에 울음 원인 정답이
없어 맞는지 평가할 수 없다. 화면은 추가로 두 구간 합의를 요구하므로 모델 진입
횟수가 화면에 표시된 결과 횟수를 뜻하지 않는다.

이 샘플은 선택한 5개 파일의 겹치는 10개 구간이며 독립 검증 세트가 아니다.
실사용 정확도·민감도·특이도 수치로 일반화할 수 없다. 이 결과에 맞춰 임계값을
조정하지 않았다. 추가로 독립된 아기·기기·환경과 말소리/음악/혼합 소음이 필요하다.
원인 정확도를 검증하려면 울음 원인 라벨의 신뢰성부터 확인해야 한다.

레이블 및 키보드 조작 구조를 검토했다. 이번 환경에는 Sites가 요구하는

## 2026-10-02 재검증 및 변경

전체 자동 테스트와 production build를 재실행했다. `validation-2026-10-02.json`의
실제 녹음 10구간 결과는 이전과 동일하다. 탐지 누락은 해결되지 않았으며 정확도
개선을 주장하지 않는다. 별도 모델 교체는 독립 검증 자료가 부족해 적용하지 않았다.

추가 회귀 검사: 마이크 전용 모드의 video:false 요청, 카메라 전환 비활성화,
후보별 행동 안내, gain 변경 시 Worker 재시작 방지, 파형 버퍼 재사용,
울음 감지 준비 및 무음·비울음 처리 시 원인 모델 미다운로드, 실제 울음에서
원인 모델 1회 지연 로딩. 기존 결과 유지/연속 후보/중복 응답/종료/권한 취소 검사 유지.

초기 필수 모델 다운로드에서 정확히 8,278,444바이트를 지연시켰다. 초기 총량은
약 19MB에서 약 11MB로 줄지만 울음 발생 후 총량은 동일하다(압축 전 파일 기준).
파형은 매 프레임 8,192바이트 임시 배열 생성에서 세션당 단일 버퍼 재사용으로
변경했고 draw는 최대 20fps다. 휴대폰 CPU·배터리·실제 로딩 초 단위는 미측정이다.
외부 웹폰트 요청을 제거하고 시스템 글꼴을 사용한다.

밝은 크림/연보라 패널, 또렷한 시작 버튼, 모바일 결과 카드와 후보별 확인 행동,
44px 터치 영역, 16px select, safe-area 여백을 적용했다. 실제 화면 QA와
iPhone/Android 권한·잠금/회전 검증은 브라우저 기능 부재로 여전히 미실행이다.
MediaPipe 런타임의 feedback-tensor 비활성화 경고는 실행 실패가 아니며
자동 검증에서 추론은 완료됐다. 이를 브라우저 콘솔 오류 없음으로 표현하지 않는다.

## 2026-10-03 원인 진단 및 결과 신선도 수정

`detector-diagnostics-2026-10-03.json`에 동일 10개 입력의 전처리 상태,
프레임별 아기 울음 점수 및 상위 세 소리 클래스를 기록했다. 누락된 울음은
YAMNet에서 말소리·웃음·고양이·염소 등으로 분류됐다. 임계값/모델 변경은 없다.
샘플 수, 겹치는 구간, 원인 정답 부재 한계도 그대로다.

추가 수정 및 회귀 검사:
- AudioWorklet에서 수집 종료 시각을 오디오 프레임 기준으로 전달한다.
- 마지막 시각은 추론 완료 시각 대신 실제 수집 시각을 표시한다.
- 처리 중 건너뛴 구간이 있으면 다음 결과와 연속 합의로 세지 않는다.
- 수집 후 10초 넘게 지연된 결과는 폐기하며 기존 후보/시각은 보존한다.
- 보정 설정을 바꿨다가 원래 값으로 되돌려도 이전 실행 결과는 폐기한다.

이는 결과 신선도와 표시 안정성 수정이다. 울음 분류 정확도 개선이 아니다.
전체 자동 검사와 production build를 실행했고 실제 모델/기존 녹음 경로도
재실행했다. 실기기/브라우저 화면 검증은 이번 환경에서도 수행하지 못했다.

## 2026-10-03 확대 비교 및 카메라 오류 복구

112개 원본 녹음(224개 겹치는 구간)으로 기존 모델, 공식 전체 YAMNet,
잠정 재현 CNN을 비교했다. 상세 결과 및 재현 절차는 `MODEL_EVALUATION.md`.
전처리 필터는 원본 44.1kHz 입력 비교에서 울음 감지가 55→53으로 줄어
운영 반영하지 않았다. 실험 코드는 배포 Worker에서 분리했다.

운영 수정: 다운샘플링으로 건너뛰는 위치를 포함한 전체 입력의 NaN/Infinity
검사, 카메라 없음/지원하지 않는 제약 조건 시 마이크 연결, 영상 재생 실패 시
카메라 트랙 해제 및 오디오 분석 유지. 권한 거절에는 자동 재요청하지 않는다.
새 회귀 테스트 및 기존 전체 테스트/production build 통과. 실제 Safari/Android
기기 권한/재생 오류 재현은 못 했으며 테스트는 API 모의 환경이다.

## 2026-10-04 입력 중단과 전송 오류 복구

마이크 mute, AudioWorklet processorerror/port messageerror는 듣기를 종료하고
트랙/작업자를 정리한다. 마지막 후보와 수집 시각은 보존하고 별도 오류 안내를
표시한다. Worker 응답 역직렬화 실패, postMessage 예외, null 응답, 잘못된
점수 범위/중복 라벨은 분석만 중지해 다시 연결할 수 있도록 한다.
모의 이벤트 주입 회귀 검사로 정리·후보 보존·재시도 버튼을 확인했다.
실제 모바일 기기의 인터럽트 검증을 대신하지 않는다. 탐지 모델 변경은 없다.

## 2026-10-04 현재 감지와 보존 후보의 분리

현재 관찰 상태를 별도 영역에 표시하고, 조용함/비울음/불확실/오류/종료 시
기존 후보에 ‘이전 소리의 결과’ 표시를 붙인다. 후보와 원래 수집 시각은
계속 보존한다. 새 세션은 후보/후보 펼침 상태를 초기화한다. 보조 순위는
기본 접힘 상태이며 확률로 표현하지 않는다. 수동 상황 확인으로 바로
이동하고 키보드 포커스를 옮길 수 있다. 검증 안내는 원본 44.1kHz 처리
실험의 55/80, 0/144와 표본·구간·원인 라벨·실기기 검증 한계를 함께 공개한다.
이 변경은 모델/임계값/탐지 정확도를 바꾸지 않는다.

회귀 검사에 현재 상태 갱신과 과거 후보 보존의 분리, 새 세션 초기화,
상황 확인/안내 열기·닫기를 추가했다. 모바일 CSS와 44px 터치 영역은
코드 검토했으나 실제 모바일 브라우저 렌더링과 마이크 검증은 수행하지 못했다.

## 2026-10-04 휴대폰 점검 계측

세션별 마이크 샘플링/입력 설정, 캡처·대기·생략·응답·오래된 응답 수,
응답 시간과 오류 횟수를 메모리에서 계측한다. 기기 식별자, 원인 라벨,
음성/영상은 점검 보고서에 포함하지 않는다. 수동 복사만 제공한다.
자동 검사는 카운터/시각/오류 기록, 재시작 초기화, 식별자 제외,
클립보드 거절 시 직접 복사 대안을 확인한다. 실기기 QA는 MOBILE_QA.md
체크리스트 모두 미실행이며 통과를 주장하지 않는다.
