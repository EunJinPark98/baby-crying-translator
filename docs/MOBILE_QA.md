실기기 통과 처리하지 않았다. API 모의 테스트와 Node의 실제 WASM
실행은 Safari/Chrome 검증을 대신하지 않는다.

## 기기에서 재현하기

기존 응애톡 URL을 iPhone Safari / Android Chrome 각각에서 연다.
사이트는 현재 소유자 전용이므로 권한을 가진 계정이 필요하다.
설정의 ‘이 휴대폰에서 작동 확인하기’에서 절차와 측정값을 확인한다.
30초 이상 듣기를 실행하고 점검 결과를 복사할 수 있다. 원인/음성/영상과
장치 식별자는 보고서에 넣지 않으며, 자동 전송하지 않는다.
보관은 메모리만 사용한다. 새 세션/새로고침 시 초기화된다.

## 측정값 해석

캡처 수는 AudioWorklet 전달 구간, 대기 수는 AI 미준비/꺼짐 상태,
분석 중 생략 수는 작업 적체를 만들지 않기 위해 버린 구간이다.
완료 응답 수에는 무음/비울음 응답도 포함된다. 응답 시간은 메인 스레드
제출부터 Worker 응답까지이며 최초 원인 모델 다운로드를 포함할 수 있다.
낮은 지연/응답 수 증가가 울음 정확도를 증명하지 않는다.
모델 준비 시간은 마지막 모델 시작 시도만 기록한다.
오류는 범주별 횟수만 기록한다. 모바일 브라우저 사용자 에이전트와
샘플링/입력 설정은 실제 기기의 값을 그대로 표시한다.
